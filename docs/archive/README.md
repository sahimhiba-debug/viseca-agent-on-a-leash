# Archive

Working documents from the build: audits, research logs, red-team reports and
intermediate decisions, kept because code comments and tests cite them as the
record of how a finding was made. They are not maintained, and several carry
figures that have since moved -- many say so in a snapshot banner at the top.

The documents that describe the system as it is now are one level up, in
[`docs/`](..): start with [THE_THESIS.md](../THE_THESIS.md) and
[CODEBASE_GUIDE.md](../CODEBASE_GUIDE.md).
