What we do not claim

  • Your account's monthly limit is real data that this wallet does not enforce.
  • The payment step here is ours and simulated.

Compromised platform

A different threat model from the Agent tab. There, a compromised agent proposes things it should not. Here the events reaching the wallet are attacked: inflated amounts, replayed authorizations, a mutated policy, a purchase answered after revocation, a worker restarted mid-flight. Fixed inputs, no network, no model — identical every run.

Six vulnerabilities. One bug.

Every defect this project found in its own code — six of them, in six separate campaigns, fixed weeks apart — turned out to be the same thing: a fact accepted from a party that is not its author.

Any system that delegates authority has these. The question is whether you can name the pattern — because none of the first five fixes prevented the sixth. Naming it turns six separate audits into one build rule.

    Delegation is not about what an agent may spend.
    It is about which facts it may author.

    Four of the six arrived the same way: someone added a field. So try it. Type a field you would like the agent to be able to send, and the real rule will answer — the same function the build runs.
