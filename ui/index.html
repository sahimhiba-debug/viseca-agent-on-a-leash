Agent on a Leash

The agent is autonomous. The authority is not. checking…

What this is

A control layer that lets a customer delegate shopping authority to an autonomous agent — without giving that agent independent payment authority.

The agent proposes purchases. It never decides whether money moves. The wallet decides — from rules compiled out of the customer's own words — and can explain every answer in plain language.

How it works

Customer writes an instruction→ Compiled to executable checks→ Agent proposes a purchase→ Wallet decides→ Allow · Ask · Block→ Single-use payment authority
The customer confirms the compiled rules before anything runs. After that a mandate can only ever be tightened — never widened, by anyone, including us.

Why it is different

Most controls ask “is this transaction permitted?”. A compromised agent need not break a rule — it controls how a job is split into individually-permitted purchases.

So the wallet also asks: has this job already been done? On the official data that catches six approved purchases worth CHF 1,787 repeating a job the customer described once.

What we do not claim

  • Not exactly-once payment — at-most-once, per process.
  • We do not cap total spending. No mandate in the official rule format can.
  • The account's monthly limit exists in the data and is not enforced by this wallet.
  • The payment step is simulated. The Viseca API has none.
